# Typography System — V3

The site now uses one explicit typography system across every page.

## Display
Cormorant Garamond — headings, logo, large pricing figures and editorial numerals.

## Interface/body
Inter — body copy, navigation, labels, buttons, metadata and utility text.

## Rules
- No page-specific font families.
- No mixed sans-serif body fonts.
- Consistent heading scale across homepage and SEO landing pages.
- Consistent uppercase/letter-spacing treatment for navigation and labels.
- Responsive type sizes for mobile.
- Font smoothing and text rendering are normalised.
- Google Fonts are loaded consistently on all pages.

This keeps the visual language editorial, premium and photography-led while maintaining readability.
